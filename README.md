# Redmit - Real People. Real Conversations.

A modern, category-first social discussion platform where people ask questions, share knowledge, discover communities, and support creators financially.

## 🚀 Features

- **Category-First UX**: Browse topics before diving into discussions
- **Global + Local Communities**: Country-based and global discussion spaces
- **Creator Monetization**: Super Thanks system for supporting creators
- **Smart Content**: Remembers your activity per category
- **Dark Navy Theme**: Professional, modern UI design
- **Mobile-First**: Fully responsive on all devices
- **Real-time Engagement**: Likes, replies, shares, bookmarks

## 🛠️ Tech Stack

- **Frontend**: React 18 + TypeScript
- **Routing**: React Router v6
- **Styling**: TailwindCSS 3
- **Icons**: Lucide React
- **Build**: Vite
- **Deploy**: Vercel
